# Architecture logique candidate
Réglementations et standards autorisés → OSCAL/Trestle → GRC → OPA/Kyverno → contrôles Prowler/Wazuh/OpenSCAP → preuves intégrité/horodatage → écarts → remédiation PR → réévaluation.
Les connecteurs sont à concevoir et qualifier. Séparer identité, accès, preuves, journal et données sensibles; aucun scanner ne remplace l'avis de conformité.
