# Gouvernance et feuille de route
Mission : ingénierie de conformité continue ouverte en Afrique francophone.
PR-only : issue → branche → PR → revue → contrôles CI → fusion. Le commit initial d'un dépôt vide est l'unique exception de bootstrap. Aucune modification manuelle d'environnement cible. Protections de branche à configurer et vérifier par administrateur.
Rôles proposés : ADVISE Solutions Engineer, BUILD Implementation Engineer, OPERATE Customer Reliability Engineer. Tout ingénieur contribue upstream selon les règles des mainteneurs.
Dédoublonnage : rechercher ID, titre, URL canonique, issues et PR avant création; mettre à jour une fiche existante lorsque possible.
Sécurité : données synthétiques, autorisation explicite pour scanners, aucun secret ni preuve client publique, analyse de licences, revue humaine des interprétations réglementaires.
Roadmap : S1 sources et LAB-001; S2 LAB-002/003; S3 LAB-004/005; S4 LAB-006; S5 LAB-007/008; ensuite démonstrations et pilotes.
